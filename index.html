O conceito Bootstrap

Bootstrap é uma biblioteca de front-end que oferece componentes e estilos prontos para acelerar a criação de interfaces responsivas.

Botões Estilos padronizados e estados de interação.
Cards Blocos organizados para agrupar informações.
Formulários Campos com aparência consistente.
Modais Janelas para avisos e confirmações.

Neste projeto, o conceito foi aplicado com componentes personalizados em HTML, CSS e JavaScript, mantendo a identidade visual praiana. Em uma versão com a biblioteca Bootstrap, esses elementos também poderiam ser montados com suas classes e componentes prontos.
